# PharmaLearn Pro

Static Bootstrap 5 pharmacokinetics learning platform generated from the supplied PDF chapter set.

## Files
- `index.html` home dashboard
- Chapter pages: absorption, distribution, metabolism, excretion, IV bolus, IV infusion/extravascular, multi-compartment
- `formula-sheet.html`, `mcq.html`, `viva.html`, `exam-notes.html`, `revision.html`
- `assets/pdf-pages/` contains the original extracted PDF slide/page images for diagram reference

## How to run
Open `index.html` in a browser, or deploy the folder to any static hosting service.

## Notes
The PDFs were image-based scans, so the platform includes extracted original page images plus structured pharmacokinetics explanations, formulas, graph guidance, exam answers, MCQs, viva, and revision notes.
